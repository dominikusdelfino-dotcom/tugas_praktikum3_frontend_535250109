# tugas_praktikum3_frontend_535250109
1. User bisa menambahkan data pengeluaran lewat input form yang berada di webnya.

2. User harus menginput nama user, nominalnya, keterangan, dan waktunya.

3. Jika user belum mengisi semua datanya, maka tombol "Tambahkan Pengeluaran" tidak bisa dipencet.

4. Setelah mengisi semua datanya, user bisa langsung klik tombol "Tambahkan Pengeluaran". Lalu hasil data yang sudah diisi sebelumnya akan muncul di tabel yang ada di webnya.

5. Untuk input nominal, tinggal ketika aja misalnya 10000. Nahh nanti sistemnya akan otomatis munculin nominal yang user input menjadi Rp10.000,00

6. Dalam tabel, disediakan tombol "Hapus" di bagian kolom "Aksi". Fungsinya yaa jelas untuk hapus data pengeluaran yang ingin dihapus oleh user.

7. Setelah klik tombol "Hapus", sistem akan menanyakan sekali lagi kepada user apakah benar user memang ingin menghapus data pengeluaran tersebut.

8. Dari semua data pengeluaran yang diinput oleh user, sistem akan otomatis menghitung total keseluruhan data pengeluarannya. Bisa dilihat total pengeluarannya di bagian bawah tabel.
